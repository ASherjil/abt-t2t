# Market data (not committed)

Real NASDAQ TotalView-ITCH 5.0 sample days, published free by NASDAQ at
<https://emi.nasdaq.com/ITCH/Nasdaq%20ITCH/> (15 days, 2018-2020; the ITCH 5.0 format is
unchanged in current TotalView). Files are 3.5-5.6 GB gzipped and stay out of git — this
directory is ignored except for this README.

    scripts/fetch_itch.sh                # 01302020 (default: most recent, busiest sample day)
    scripts/fetch_itch.sh 12302019       # a quieter day for contrast

Format: "BinaryFILE" — each message is a 2-byte big-endian length followed by the raw ITCH
message; no MoldUDP64 framing. The readers in `src/t2t/replay/` handle both the .gz and
the uncompressed form transparently.

Expected layout:

    data/itch/01302020.NASDAQ_ITCH50.gz      full day, all symbols (download)
    data/itch/01302020.AAPL.itch             per-symbol extract (generated by itch_replay --extract)

Replaying the extract through the exchange simulator (`[replay]` in `config/exchange_sim.toml`):
every message in the file is sent to the DUT unchanged, at real time-of-day pacing by default
(`speed = 0` replays as fast as possible, `loops = 0` repeats the day until stopped); the venue
mirrors the symbol's book so the DUT's own orders trade against the recorded liquidity, with
fills shadowed on top of the real history rather than rewriting it.
